# KeepAwake 项目状态与交接

## 一句话现状

截至 2026-10-09，KeepAwake 的 App Store 公开版本为 2.0.3；GitHub 最新正式 Release 为 v2.0.2。GitHub v2.0.2 Release 说明称其 DMG 使用 Developer ID 签名、尚未公证。2.0.3（Build 21）的独立 DMG 已签名并获 Apple 公证，但尚未发布到 GitHub；两个分发渠道的版本与包状态需分别核验。

当前本机 `/Applications/KeepAwake.app` 的版本与公开发行版本不同，以安装包 `Info.plist` 实际读取为准。

## 接手三步

1. 有新 App Store 版本时，在 App Store Connect 核对其构建处理、审核与发布状态；不要把商店版本号套用到 GitHub DMG。
2. 发布独立 DMG 前，确认所选版本、签名、公证和 Gatekeeper 检查结果，并核对上传包 SHA-256。
3. 更新公开下载信息时同步检查 GitHub README 与主站版本标签，并在线回读验证。
