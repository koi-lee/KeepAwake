# KeepAwake 项目状态与交接

## 一句话现状

KeepAwake 当前在 `main` 分支，合盖授权诊断修复已推送；待发布版本为 `2.0.3 (Build 21)`。Build 21 已上传 App Store Connect，等待 Apple 处理；Developer ID DMG 因签名私钥访问卡住，尚未重新生成或公证。

## 接手三步

1. 在 App Store Connect 确认 Build 21 处理完成，关联到 2.0.3 版本并检查提交审核所需资料。

3. 将版本号和发布记录与 GitHub 同步；用户已有保持本地与 GitHub 同步的授权。

## 已知坑与环境注意

- 现有合盖授权通过 AppleScript `do shell script ... with administrator privileges` 运行长期 shell 循环；失败的原因可能是授权取消、系统未显示密码框或 pmset/握手失败，不能仅凭录屏确定是哪一种。
- 录屏显示的是通用失败提示，截图系统为 Apple M1、macOS Tahoe 26.6.2。当前工程构建目标 macOS 13+，但真实授权流程仍需目标机验证。
- 部分会话的 SwiftPM 沙箱可能因用户缓存访问被系统拒绝；本次在获准的开发环境中 `swift test` 已通过 13/13。
