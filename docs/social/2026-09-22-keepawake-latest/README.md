## 统一传播主张

**主标题：** Mac 别睡，AI 任务继续跑

**一句话介绍：** KeepAwake 是一款本地运行的 macOS 菜单栏工具，可按应用自动阻止系统睡眠，也支持定时或一直保活，并在低电量时自动停下。

**统一署名：** Koi的AI转型手记
